# fx-tracker

달러·엔 매수 기록과 과거 환율을 확인하는 개인용 웹앱. 빌드 도구 없이 브라우저에서 바로 도는 정적 PWA입니다.

**이 도구는 매수·매도 시점을 추천하지 않습니다.** 데이터 표시와 사용자가 입력한 기록의 계산만 합니다. 투자 판단과 세무 처리는 전문가 확인을 권장합니다.

## 무엇을 하나

| 탭 | 내용 |
|---|---|
| 현황 | USD·JPY 차트(이동평균·내 매수 시점), 과거 분포에서의 위치(백분위·이격도·52주), 변동성 확률구간, 목표환율 알림 |
| 내 보유 | 평균단가·평가손익·본전 환율, 누적 환전 비용, 매수 집중도 진단, JSON 백업 |
| 계획 | 분할매수 vs 일시불 과거 비교, 분할매수 계획 관리 |
| 면세점 | 오늘·내일 적용환율(전일 매매기준율 기준), 최근 7일 적용환율 추이, 상품가 환산 |
| 모델 성적표 | 예측 모델 4종 + walk-forward 백테스트 (Theil's U, 방향 적중률 신뢰구간) |

### 예측에 대해

단기 환율 예측은 Meese-Rogoff(1983) 이후 40년 넘게 랜덤워크를 안정적으로 이기는 모델이 나오지 않은 영역입니다. 이 앱의 예측 모델은 맞히라고 넣은 게 아니라 **실제로 못 맞힌다는 것을 본인 데이터로 확인하라고** 넣었습니다. 예측값 옆에는 항상 Theil's U와 방향 적중률이 붙어 나가며, 성적표 없는 예측 숫자는 화면에 표시하지 않습니다.

## 환율 데이터

역할을 둘로 나눕니다. 두 소스는 0.4% 안팎 차이가 나므로 차트에 섞으면 계단이 생깁니다.

| 용도 | 소스 |
|---|---|
| 차트·백분위·이동평균·백테스트 | [Frankfurter](https://frankfurter.dev) (ECB 공시, 무료·키 불필요·CORS 허용, 최근 15년) |
| 현재 환율·평가손익·환전 비용·면세점 | **한국수출입은행 매매기준율** — `data/rates.json` |

`data/rates.json`은 GitHub Actions가 매 영업일 받아서 커밋합니다. 서버가 필요 없고, **인증키는 GitHub Secrets 안에만 있습니다.**

## 설정 (한 번만)

### 1. 한국수출입은행 인증키 발급 (무료, 5분)

1. [현재환율 API 상세](https://www.koreaexim.go.kr/ir/HPHKIR020M01?apino=2&viewtype=C) → **「인증키 발급신청」**
2. 본인인증(휴대폰 또는 아이핀). 회원가입은 없습니다.
3. [나의 인증키 발급내역](https://www.koreaexim.go.kr/ir/HPHKIR021M01)에서 키 확인

알아둘 것:
- 하루 **1,000회** 제한 (`result:4`). 이 워크플로는 하루 10회 안팎만 씁니다.
- **키는 2년마다 만료됩니다.** 개인정보 보유기간이 지나면 파기되고 `result:3`이 돌아옵니다. 파기 전 등록 이메일로 재동의 안내가 오며, 재동의하면 2년 연장됩니다. 파기된 키는 재사용 불가입니다.
- 환율은 **영업일 11시 전후** 갱신됩니다.
- 사내망 방화벽이 있다면 API 호출 대상 IP는 `39.115.136.167` 입니다.

### 2. 저장소에 키 등록

**Settings → Secrets and variables → Actions → New repository secret**

| Name | Secret |
|---|---|
| `KOREAEXIM_KEY` | 발급받은 인증키 |

> 저장소가 public이므로 키를 코드나 `data/`에 절대 넣지 마세요. Secret에만 둡니다.

### 3. 첫 실행

**Actions → 환율 갱신 → Run workflow**

과거 데이터를 함께 채우려면 `from`에 시작일(예: `2024-01-01`)을 넣고 실행하세요. 영업일 하나당 1회 호출이므로 2년치면 약 500회로 하루 한도 안에 들어갑니다. 이후에는 평일 12:30(KST)에 자동으로 하루치씩 추가됩니다.

### 4. 앱 열기

**Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**

`https://jugga1004.github.io/fx-tracker/` 로 열립니다. 앱은 같은 저장소의 `./data/rates.json`을 읽으므로 **따로 설정할 게 없습니다.**

## 파일 구조

```
index.html          화면 마크업
app.js              화면 렌더링 / 상태 / 탭
fx-data.js          ECB 시계열 어댑터 + localStorage 캐시
fx-domestic.js      국내 매매기준율 (data/rates.json 읽기)
fx-stats.js         백분위·이동평균·변동성 밴드
fx-models.js        예측 모델 + walk-forward 백테스트
portfolio.js        매수 기록 / 평단가 / 손익 / 계획 / 면세점
chart.js            SVG 라인차트 (라이브러리 없음)
data/rates.json     Actions가 채우는 국내 매매기준율
scripts/            수집 스크립트 (Actions에서만 실행)
```

빌드 스텝이 없습니다. ES 모듈 대신 일반 `<script>` 태그와 전역 네임스페이스를 씁니다(`file://`에서 ES 모듈이 CORS로 막히기 때문).

## 알아둘 것

- 개인 매수 기록은 **브라우저 localStorage에만** 저장되며 저장소에 올라가지 않습니다. 브라우저 데이터를 지우면 사라지니 「내 보유 → 데이터 백업」에서 가끔 내보내세요.
- `index.html`을 로컬에서 직접 열면(`file://`) 브라우저가 `data/rates.json` 읽기를 막아 ECB 환율로만 동작합니다. 정상입니다.
- ECB 환율은 유럽시간 16시경 공시라 한국시간 밤에야 당일 값이 들어옵니다. 주말·유럽 공휴일에는 데이터가 없습니다.
- 실제 거래 전에는 거래 은행의 고시환율을 확인하세요.
- **면세점 적용환율과 환전 환율은 다릅니다.** 적용환율은 달러 표시가를 원화로 바꾸는 환산율이라 매매기준율 그대로이고 스프레드가 없습니다. 환전 환율은 실제로 외화를 사고파는 거래율이라 매매기준율에 스프레드(현찰 통상 ±1.75%)가 붙습니다.
- 면세점 적용환율은 "전일 고시 매매기준율"이라는 업계 통용 규칙에 따른 **추정치**입니다. 원천은 서울외국환중개 고시이고 이 앱의 값은 한국수출입은행 고시라 소수점까지 같다는 보장은 없습니다.
