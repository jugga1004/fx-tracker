관심 상품

면세점 달러 표시가를 적어두면 적용환율이 바뀔 때마다 오늘·내일 원화가가 자동으로 갱신됩니다.

적용환율과 환전 환율은 다릅니다. 적용환율은 표시가를 원화로 바꾸는 환산율이라 매매기준율 그대로이고 스프레드가 없습니다. 반면 은행에서 달러를 사면 매매기준율에 스프레드(현찰 통상 +1.75%)가 붙습니다. 그래서 현찰을 환전해 쓰는 것보다 원화로 결제하는 쪽이 유리한 경우가 많습니다. 다만 카드 결제는 카드사 환율과 수수료가 따로 붙으니 결제 수단별 조건은 확인이 필요합니다.

관심 상품 백업

등록한 관심 상품은 이 브라우저에만 저장됩니다. 브라우저 데이터를 지우면 사라지니 가끔 내보내 두세요.

노선 등록

노선과 날짜를 등록해두고 가격을 찍어 쌓으면 내가 본 가격 중 지금이 어디인지가 나옵니다. 예측이 아니라 기록입니다. 지금은 직접 입력해야 하고, 자동 수집은 항공권 API 키가 연결되면 붙습니다.

이 도구는 데이터 표시와 등록한 관심 상품의 환산만 합니다. 매수·매도 시점을 추천하지 않습니다. 투자 판단과 세무 처리는 전문가 확인을 권장합니다.

환율은 ECB 공시 기준이라 서울외국환중개 매매기준율·은행 고시환율과 다르며, 주말과 유럽 공휴일에는 데이터가 없습니다. 실제 거래 전 거래 은행의 고시환율을 반드시 확인하세요.
